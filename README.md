# ONG Mãos que Ajudam

Projeto da disciplina de Desenvolvimento Front-End (Experiência Prática 1): site em HTML5 semântico para uma ONG fictícia.

## Páginas

- `index.html`: apresentação da ONG, missão, visão, valores e contato
- `projetos.html`: projetos sociais, voluntariado e doações
- `cadastro.html`: formulário de cadastro com validações nativas do HTML5 e máscaras de CPF, telefone e CEP

## Estrutura

```
projeto-ong/
├── index.html
├── projetos.html
├── cadastro.html
├── imagens/   (SVG, WebP e JPG/PNG servidos via <picture>)
└── js/
    └── mascaras.js
```

Os três arquivos HTML foram validados no [W3C Validator](https://validator.w3.org/) sem erros ou avisos.

Para visualizar, abra o `index.html` no navegador.
